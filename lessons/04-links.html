Links

Links let users click to go somewhere else — another page, another site, or a section on the same page.

The a tag

a stands for "anchor". It needs an attribute called href that says where to go.

Live example

Go back to the course home page.

<a href="../index.html">course home page</a>

Breaking down the syntax

<a href="URL_GOES_HERE">clickable text</a>
     ^^^^^ attribute name
           ^^^^^^^^^^^^^^^ attribute value (in quotes)

Attributes are extra details on an opening tag. Format: attributeName="value"

Types of links

1. Link to another file on your computer (relative path)

<a href="lessons/05-lists.html">Go to Lesson 5</a>

Path is relative to the current file's folder — like a file path on your Mac.

2. Link to a website (absolute URL)

<a href="https://developer.mozilla.org">MDN docs</a>

3. Open in a new tab

<a href="https://example.com" target="_blank">opens new tab</a>
Java comparison: A link is like calling a method that jumps somewhere else. href is the destination. The text between the tags is the button label.
