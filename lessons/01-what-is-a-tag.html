What is a tag?

HTML is not a programming language like Java. It's a markup language — you wrap content in tags to tell the browser what each piece is.

Tags look like this

<p>Hello world</p>

Break it down:

  • <p> — opening tag (starts a paragraph)
  • Hello world — the content (what the user sees)
  • </p> — closing tag (ends the paragraph — notice the /)

Together, opening tag + content + closing tag = an element.

Java comparison: Think of a tag like punctuation that labels meaning. In Java you write System.out.println("Hello"); to print text. In HTML you write <p>Hello</p> and the browser displays it — no compile step, no main method.

Rules to remember

  1. Most tags come in pairs: open, then close.
  2. Closing tags have a / before the name: </p>
  3. Tag names are lowercase (convention).
  4. Content goes between the tags, not outside them.
Common mistake: Forgetting the closing tag. <p>Hello with no </p> still shows text, but everything after it might get swallowed into that paragraph. Always close your tags.
