Attributes

You've already used attributes (href, type, placeholder). This lesson covers the ones you'll use most, especially id and class.

What is an attribute?

Extra information on an opening tag:

<tag name="value">content</tag>

id — unique name for one element

Like a variable name. There should only be one element with each id on a page.

<ul id="expense-list"></ul>
     ^^^^^^^^^^^^^^ JavaScript will find this later to add items
Java comparison: id="expense-list" is like naming a variable expenseList so you can refer to it later. JavaScript will do document.getElementById("expense-list") — same idea as using a variable name.

class — label for styling groups

Multiple elements can share the same class. Used heavily in CSS (next course section).

<li class="expense-item">Coffee — $4.50</li>
<li class="expense-item">Bus — $30.00</li>

Other attributes you've seen

  • href — link destination (on <a>)
  • src — image file path (on <img>)
  • type — input/button behavior (on <input>, <button>)
  • placeholder — hint text in an empty input
  • for — connects a label to an input's id
  • lang="en" — page language (on <html>)
  • charset="UTF-8" — character encoding (on <meta>)

Self-closing tags

Some tags have no content and no closing tag:

<input type="text">
<img src="photo.jpg" alt="A photo">
<br>
<meta charset="UTF-8">

Putting it all together

Here's what a complete expense tracker HTML page looks like — structure only, no styling or behavior yet:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Expense Tracker</title>
</head>
<body>
  <h1>Expense Tracker</h1>

  <form id="add-form">
    <input id="description" type="text" placeholder="Description">
    <input id="amount" type="number" placeholder="Amount">
    <input id="category" type="text" placeholder="Category">
    <button type="button">Add Expense</button>
  </form>

  <h2>All Expenses</h2>
  <ul id="expense-list"></ul>

  <p>Total: <strong id="total">$0.00</strong></p>
</body>
</html>
