The page skeleton

Every HTML file follows the same basic structure. Once you know this shape, you can open any web page's source and recognize it.

The template every page uses

<!DOCTYPE html>               <!-- tells browser: this is HTML5 -->
<html>                        <!-- wraps the entire page -->
  <head>                      <!-- invisible setup stuff -->
    <title>Page Title</title>   <!-- text in the browser tab -->
  </head>
  <body>                      <!-- everything the user sees -->
    <h1>Hello</h1>
  </body>
</html>

What each part does

<!DOCTYPE html> One line at the very top. Not a tag — a declaration.
<html> The root. Everything else goes inside it.
<head> Metadata — title, character encoding, links to CSS. Not visible on the page itself.
<title> The text in the browser tab. Look at your tab right now — it says "Lesson 2 — The page skeleton".
<body> All visible content: headings, text, images, forms, everything.
Java comparison: The skeleton is like the file structure of your Java project. public class Main is the outer wrapper; public static void main is where execution starts. In HTML, <body> is where visible content lives.

Indentation (spacing)

HTML doesn't care about spaces or indentation — the browser ignores extra whitespace. But you should indent nested tags so you can read your code: 

<body>
  <h1>Expense Tracker</h1>    <!-- indented: inside body -->
  <p>Welcome.</p>           <!-- same level as h1 -->
</body>

HTML comments

Lines the browser ignores — notes for you:

<!-- this is a comment, browser skips it -->
