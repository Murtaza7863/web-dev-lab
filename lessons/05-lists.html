Lesson 5 of 7

Lists

Your Java expense tracker stores expenses in a list (ArrayList). On a web page, you show lists with HTML list tags.

Unordered list (bullets) — ul + li

Live example — like viewAllExpenses()
  • Coffee — $4.50 — Food
  • Bus pass — $30.00 — Transport
  • Netflix — $15.99 — Entertainment
<ul>                          <!-- ul = unordered list (bullets) -->
  <li>Coffee — $4.50 — Food</li>   <!-- li = list item -->
  <li>Bus pass — $30.00 — Transport</li>
  <li>Netflix — $15.99 — Entertainment</li>
</ul>

Ordered list (numbers) — ol + li

Live example — like your CLI menu
  1. Add Expense
  2. Remove Expense
  3. View All Expenses
  4. Exit
<ol>                          <!-- ol = ordered list (1, 2, 3...) -->
  <li>Add Expense</li>
  <li>Remove Expense</li>
</ol>

The pattern

  1. Pick ul (bullets) or ol (numbers)
  2. Put one <li> inside for each item
  3. Never put text directly inside ul — always wrap in li
For the expense tracker web app: You'll use a <ul id="expense-list"> as an empty container. Later, JavaScript will add <li> items when someone adds an expense. For now, you can hard-code a few items to practice.
