# Web Dev Lab

A PWA course: you already know loops and classes. This teaches **how to build** — spec, data, verbs, layers — then names the web costumes (HTML, APIs, Spring) on the same expense tracker.

GitHub Pages hosts the client. Spring cannot run on Pages. The Lab is a mock API so `fetch`/CRUD are still real.

Companion Java CLI: [Murtaza7863/expense-tracker](https://github.com/Murtaza7863/expense-tracker).

## Run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080 (not `file://`). Phone or laptop — Chrome/Edge can **Install** it as a window.

## How to play

1. **Placement run** — from memory. Soft spots, not a grade.
2. **The Map** first — SWE from scratch (the missing homework).
3. Then costumes: Page → Skin → Hands → Call → Dungeon → Other Process → Install.
4. **Lab** — live CRUD. HTTP log is the spellbook.
5. **Loot** — buzzwords unlock when you earn them.

XP, ranks, combos, badges. Wrong answers in quests you can retry; placement still advances.

## GitHub Pages

Push `main` → `.github/workflows/pages.yml` deploys this folder.

One-time: **Settings → Pages → Source: GitHub Actions**.
